# Микрофон очков — прототип для iPhone, 0.1

Первый этап для Telegram без телефона в руках: проверить, доступен ли
микрофон твоих Meta Ray-Ban Display через системный Bluetooth HFP на iPhone.
Это самостоятельное приложение, а не обновление сайта rayban-telegram.

## Что готово

- Нативный интерфейс SwiftUI, iOS 17 и новее.
- Разрешение микрофона только по кнопке.
- Список только Bluetooth HFP-входов; выбор конкретного устройства.
- Проверка фактического входа перед записью и каждые 0,1 секунды во время неё.
- Запись M4A/AAC, уровень звука, предел 120 секунд, прослушивание,
  системное меню сохранения/отправки и удаление.
- При уходе с экрана приложения запись останавливается.
- Нет сервера, Telegram-ключей и отправки аудио по сети.

**Статус:** исходники подготовлены на Windows. Xcode здесь отсутствует,
поэтому компиляция и работа на iPhone ещё не подтверждены. Сборку выполнит
GitHub Actions. Получение микрофона именно твоих очков ещё предстоит проверить.
Приложение не использует закрытый код Instagram и не требует SDK Meta:
этот этап проверяет стандартный аудиомаршрут iOS.

## Шаг 1. Получить файл приложения без собственного Mac

1. Распакуй архив в отдельную папку.
2. На GitHub создай **отдельный публичный** репозиторий `glasses-mic-ios`.
   Ничего не заменяй в `rayban-telegram`.
3. На странице репозитория нажми Upload files. Перетащи содержимое
   распакованной папки: `Sources`, `.github`, `project.yml`, README и остальные
   файлы. Файл `project.yml` должен находиться в корне репозитория.
   Важно загрузить `.github/workflows/build-ios.yml` с сохранением пути.
4. Нажми Commit changes.
5. Открой вкладку **Actions**. Если GitHub предлагает включить workflows,
   включи их для своего репозитория.
6. Выбери **Build iPhone prototype** → **Run workflow** → **Run workflow**.
7. Дождись зелёного результата. Если результат красный, открой первый
   неудачный шаг и пришли текст ошибки: файл IPA пока не готов.
8. Внизу страницы завершённой сборки, в **Artifacts**, скачай
   `GlassesMic-unsigned`. Распакуй скачанный ZIP — внутри будет
   `GlassesMic-unsigned.ipa`.

GitHub предоставляет стандартные macOS runners бесплатно для публичных
репозиториев. Workflow только собирает приложение, тесты не запускает.
IPA пока не подписан и сам по себе на iPhone не установится.

## Шаг 2. Установка через Windows

Возможный путь — Sideloadly: https://sideloadly.io/
Это сторонний установщик; его авторы заявляют поддержку Windows и
бесплатных Apple ID. Этот проект ещё не проходил установку через него.

1. Скачай Sideloadly **с указанного официального сайта** для Windows.
2. Выполни его инструкции по зависимостям Apple для Windows.
3. Подключи iPhone кабелем USB, разблокируй и подтверди доверие компьютеру.
4. Открой Sideloadly, выбери iPhone и файл `GlassesMic-unsigned.ipa`.
5. Для подписи установщик попросит Apple Account и подтверждение входа.
   Вводи их самостоятельно в установщике; не присылай пароль и коды в чат
   и не добавляй их в GitHub. Без этого бесплатная подпись не выполняется.
6. Запусти установку. Если получишь ошибку, остановись и пришли её текст.
7. Если iPhone потребует доверие разработчику: Настройки → Основные →
   VPN и управление устройством → профиль твоего аккаунта → Доверять.
8. Если iPhone потребует режим разработчика: Настройки → Конфиденциальность
   и безопасность → Режим разработчика. Следуй подсказкам телефона.

Бесплатные профили Apple действуют 7 дней. Приложение нужно повторно
подписывать/обновлять; это ограничение Apple, не Telegram.
Не покупай платный аккаунт ради непроверенного прототипа.

## Шаг 3. Проверка на твоих очках

1. Подключи очки к iPhone по Bluetooth. Закрой звонки и другие записи.
2. Открой «Микрофон очков» на iPhone.
3. Нажми «Разрешить микрофон и найти устройства», разреши микрофон.
4. В списке выбери **название своих очков**, а не другую гарнитуру.
5. Нажми «Начать запись». Убедись, что «Фактический вход» показывает очки
   и Bluetooth HFP. Приложение не начинает запись на встроенном микрофоне.
6. Оставь телефон на несколько метров дальше, говори тихо рядом с очками,
   запиши 10 секунд → Стоп → Прослушать запись.
7. Сообщи фактический вход и слышен ли голос. Это важнее одних движущихся
   полосок уровня: они сами по себе не доказывают, какой микрофон используется.

Если список пуст, этот способ пока не предоставил Bluetooth-вход.
Если источник меняется во время записи, приложение останавливается;
до обнаружения смены краткий фрагмент может попасть с другого микрофона.
Файлы находятся во временном каталоге приложения и могут удаляться iOS.

## Следующий этап после успешной проверки

Этот прототип пока запускается с телефона и не выполняет исходную цель
целиком. Далее потребуются команды Старт/Стоп с веб-интерфейса очков,
доставка записи в Telegram и проверка работы iPhone при заблокированном
экране. Нельзя обещать работу телефона в кармане до отдельной проверки
фонового выполнения. Текущий прототип намеренно останавливается в фоне.

Для совместимости с iOS 17 в коде используется прежнее имя опции
`.allowBluetooth` (HFP). На новых SDK оно может вызывать предупреждение
об устаревании; опция `.allowBluetoothHFP` — новое имя того же назначения.
